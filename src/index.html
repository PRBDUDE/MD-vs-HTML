Tables

To create tables, use the following syntax: 

    
        <table>
            <tr>
                <th>Column 1</th>
                <th>Column 2</th>
                <th>Column 3</th>
            </tr>
            <tr>
                <td>Row 1,1</td>
                <td>Row 1,2</td>
                <td>Row 1,3</td>
            </tr>
            <tr>
                <td>Row 2,1</td>
                <td>Row 2,2</td>
                <td>Row 2,3</td>
            </tr>
        </table>

Blockquotes

To create blockquotes, use the following syntax; 

    
        <blockquote>
            <p>
            This is a block quote.
            </p>
            <p>
            It can span multiple lines.
            </p>
            <p>
                It can contain <strong>bold</strong>, <i>italic</i>, <del>strikethrough</del> and <u>underline</u> text.
            </p>
            <p>
                It can also contain code blocks:
            </p>
            <pre>
                <code>
                    print("Hello, World!");
                </code>
            </pre>
        </blockquote>
